## Правила ведения проекта

1. После каждого законченного этапа обновлять этот файл.
2. Не отмечать тестирование выполненным, пока проект не запускался в Godot.
3. Не ломать уже работающие системы ради преждевременного усложнения.
4. Новые предметы, квесты, враги и заклинания по возможности описывать данными.
5. Каждый PR должен содержать описание изменений, способ проверки и известные ограничения.
