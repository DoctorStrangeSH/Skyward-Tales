# Первый остров — настройка оформления

Используется один утверждённый стиль. Водопад и сцена острова используют те же исходники, что и игра; отдельного демонстрационного рисунка нет.

## Изменить водопад мышью в Godot

1. Откройте сцену scenes/regions/greenreach_waterfalls.tscn.
2. Выберите EastLakeSource. В инспекторе задайте Stream Width (ширина), Drop Length (высота) и Flow Speed (скорость). По умолчанию ширина 64 мировых пикселя вместо прежних 20.
3. Water Tint меняет оттенок воды, Cloud Fade — долю потока, растворяющуюся внизу. Animate In Editor включает анимацию прямо в редакторе. Нулевая скорость останавливает поток.
4. Сохраните сцену: игра подхватит эти значения при следующем входе в локацию.

Для нового источника добавьте экземпляр scenes/props/island_waterfall.tscn в сцену острова. Точка Node2D — середина верхней кромки воды; ширина меняется симметрично относительно неё. В редакторе поток виден благодаря @tool. Во время игры анимация останавливается вместе с паузой.

Если terrain.waterfall_scene указан, он заменяет список terrain.waterfalls; оба способа не накладываются друг на друга. Выходы мостов остаются свободными. Для других локаций сохраняется настройка через список x/width/drop/speed.

## Пересобрать землю и нижний фон

python3 tools/art/island01_polish.py

Нужны Pillow 11.3.0, numpy 2.2.6 и scipy 1.15.3. Скрипт читает одобренные исходники из assets/New Sprites/Skyward_Tales_All_Sprites.zip и отслеживаемые текстуры облаков. Старый отсутствующий пакет incoming не нужен.

Земля сохраняет игровые тропы, озёра и места объектов. Убирается удвоение цветочного декора; цветы остаются группами. Тёплый оттенок травы становится спокойнее. Нижний фон содержит небо, облака и мосты; скалы рисует CliffRim, воду — редактируемая сцена. Поэтому старые нарисованные водопады не дублируют анимацию.

Результаты: assets/world_hd/greenreach_ground.webp, greenreach_apron_bottom.webp и greenreach_art_build.json с контрольными суммами исходника и результата.

## Проверка

Тесты tests/island_style.gd и tests/waterfall_scene.gd проверяют привязку потока, изменение размеров, скорость, паузу, поля инспектора и отсутствие дублей. Workflow Island art review пересобирает графику и делает кадры настоящей игры при фиксированном полуденном свете. Два ракурса относятся к одной сцене и одному стилю.

Полное художественное совпадение с эталоном оценивается по кадрам из движка, а не по успешному headless-тесту.
